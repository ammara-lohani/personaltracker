Got Questions?

Frequently Asked Questions

Everything you need to know about SpendWise and how it works.

Can I view my expenses from previous months? +
Yes! In both the Dashboard and Analytics sections, you can open the month dropdown selector or use the Previous/Next buttons to explore any historical month (e.g., July 2026). All metrics, charts, and transaction lists update dynamically.
Can I create my own custom categories? +
Absolutely. SpendWise allows you to create custom categories with your own custom labels, emoji icons (like 🍔, 🚗, ✈️, 💻), and custom color dots from our 12-color palette.
What happens to my expenses if I delete a category? +
Your expenses are 100% safe. SpendWise will prompt you and automatically reassign all existing transactions in that category to "Uncategorized" so that zero expense history is lost.
Does SpendWise work on my mobile phone? +
Yes! The interface is built with responsive CSS Grid and Flexbox, featuring touch-friendly cards, slide-up modal sheets, and a dedicated bottom navigation bar on mobile screens.
Is SpendWise free? +
SpendWise is completely free for personal use with unlimited transaction tracking, custom categories, and analytics.
